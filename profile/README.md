# Allplan

> Allplan keeps floors, walls, and drawings on one Windows desk: open the model, finish the sheet, and leave a site note.

---

## Session Card

| Slice | What you do in Allplan | What remains |
|-------|------------------------|--------------|
| Arrival | Open Allplan and name today's building model | A titled project |
| Focus | Keep only live floors on the Allplan workspace | A short floor list |
| Check | Read the Allplan drawing set before a large wall change | A confirmed sheet |
| Handoff | Mark finished sheets inside Allplan | A site note |

## Four Beats

1. **Name the model.** Give the Allplan project a short title before you touch floors.
2. **Pin the live floors.** Keep current sheets on the Allplan workspace and leave archived wings aside.
3. **Check the set.** Read the Allplan drawing summary before you move a wall.
4. **Close the loop.** Clear finished sheets so the next Allplan visit does not start with a search.

## First Questions

**Does Allplan replace every other program?**
No. Allplan sits beside the viewer, browser, and files you already use.

**Can two people share one computer?**
Yes. Each person keeps a separate Allplan profile.

**What should a new user try first?**
One small Allplan floor today, then the same project workspace tomorrow.

## Who Sits Down at Allplan

- **Architect** — floors and walls stay on the Allplan model.
- **Drafter** — sheets stay attached to the same workspace.
- **Handoff** — the next person can read the Allplan site note without a tour.

## Field Note

Allplan is easier to trust when the model stays smaller than the folder it came from. A named project shows what is active, the sheets show what you will touch today, and the site note tells the next person what changed.

## One Real Pass

Pick a building that already has a name. Open it in Allplan, keep only those floors on the workspace, and finish one sheet you can see.
